## English glosses of key terms (first-use reference)

- afzuiging = extraction/suction; "folie naar buiten" = film (blown) outwards; vocht = moisture
- Compactor temperatuur = compactor temperature; "kans op plastificatie" = risk of plastification (premature melting in the compactor)
- "vollopen vacuum" = vacuum (zone) flooding/filling up
- Laserfilter zone = laser filter (melt filter) temperature zone
- Bevulling / Entleering MAS = filling / emptying level of the MAS units (German loanwords; MAS = the Austrian MAS extruder/DRD dryer system); "overbelasting" = overload; "doorzet" = throughput
- Temperatur solwert DRD MAS = temperature setpoint (German "Sollwert") of the DRD (dry-cleaning/dryer) MAS
- Heiz register = heating register (German); target "Ein" = ON (German)
- Toerental = rotational speed; maalmolen = grinding mill (target is motor current in Amps)
- V10 = tank/vessel designation on lijn 5; "aflaat tijd klep" = drain valve time; "puls tijd" = pulse time; "pauze tijd" = pause time; "vol zand" = full of sand; "In hand" = in manual mode
- vul niveau = fill level; brugvorming = bridging; looptijd = run time; slierten = strands/stringers
- DSD schroef = DSD screw (DSD = Duales System Deutschland post-consumer feed); afkeur = rejects
- persschroef = press screw; gasvorming = gas formation (voids in pellets)
- Lijn 5 vacuum target "minus 0,7-0,9 bar" = −0.7 to −0.9 bar (vacuum)
