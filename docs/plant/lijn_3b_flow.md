## Sectie 1 — Droog diagram (materiaalstroom), 20-04-2023

### Layout
Blokken lichtbeige met afgeronde hoeken, drie rijen. Rij 1 (boven) stroomt links→rechts (wasgedeelte). Rij 2 (midden) stroomt rechts→links (drooggedeelte), met twee parallelle mechanische drogers. Rij 3 (onder) stroomt links→rechts (extrusie). Geen maalmolen in deze lijn — de Rafter zit vooraan in het natte deel.

### Rij 1 (boven, links → rechts) — wasgedeelte
1. **Vuilsnipper silo 3b** (dirty-shred silo 3b)
2. → **Doseerschroef M11a** (dosing screw M11a)
3. → **Rafter** (Rafter — nat maal-/wasapparaat; exacte functie/type niet op diagram vermeld)
4. → **Ontwaterschroef van rafter** (dewatering screw of the rafter)
5. → **Frictiescheider 210** (friction separator 210)
6. → **Intrekrol flotatie tank** (intake roller flotation tank)
7. → **flotatie tank** (verbatim met kleine letter; flotation tank)
8. → **Uittrek rol flotatie tank** (extraction roller flotation tank)
9. → **Ontwater schroef** (dewatering screw)
10. → (lijn langs rechterrand omlaag) → **Frickischeider li/re** [sic] (friction separator left/right)

### Rij 2 (rechts → links) — mechanisch en thermisch drogen
**Frickischeider li/re** splitst naar twee parallelle drogers:
- → **Mechanische droger 310** (mechanical dryer 310)
- → **Mechanische droger 311** (mechanical dryer 311)

Beide drogers → **Ventilator** (fan; blok zonder nummer, rechts van Verdeelwals) → **Verdeelwals** (distribution roller) → **Thermische droger** (thermal dryer) → **ventilator** (verbatim met kleine letter; blok zonder nummer, links van Thermische droger) → **Ringventilator** (ring fan) → (lijn links omlaag) → **Extruder silo**

Extra blok onder Thermische droger: **Heater** met pijl omhoog **Heater → Thermische droger** (hete lucht).

### Rij 3 (onder, links → rechts) — extrusie
**Extruder silo** → **Compactor band** → **Compactor** → **Extruder laserfilter vacuum** (extruder with laser filter and vacuum degassing) → **Kopfilter & heetafslag** (head filter & hot die-face pelletizing) → **Ontwaterzeef** (dewatering screen) → **Centrifuge** → **Weegschaal** (weighing scale) → **MS / LS silo buiten** (MS/LS outdoor silo)
