Machine-extracted structured inventory of `docs/plant/hmi_screens_2026-07-26/`.
The `.dc.html` files remain the layout spec; THIS file records what the

## Ground-truth rule

**The PHOTOS in `assets/reference_photos/hmi/` are authoritative. The mockups
are a transcription and contain at least one fabricated row, several
omissions, and many values zeroed during transcription.** Port from the photo,
use the mockup for layout. Never treat a mockup literal as plant data.

## SYSTEMATIC FINDINGS — read before porting any screen

Two patterns run across the whole set. Both were found by reading each mockup
against its source photograph; neither is visible from the HTML alone.

### 1. EVERY unit screen omits its 3D isometric machine mimic

The real Siemens HMI unit screens all carry an isometric drawing of the machine
— lower-left quadrant or top-centre — and it is **not decoration**: it is where
live state is shown. Confirmed omitted on **at least 7 screens**:

| Screen | What the mockup dropped |
|---|---|
| L3C.1 Doseer Silo | isometric silo + 3 status lamps, AND the vertical 0-300 cm level bargraph — *the only live level indication on the screen* |
| L3C.3 Bezinkafscheider | isometric sink-float separator with **BLUE-filled water bays visualising tank level** — *the only water-level cue on the real screen* |
| L3C.4 Frictiescheider | isometric pair of friction separators (yellow drive motors) |
| L3C.5 Transportschroef | isometric pair of inclined screw conveyors |
| L3C.10 Transportschroef | isometric inclined screws with red/white/green status lamps |
| L3C.11 Flotatietank | isometric flotation tank (paddle row, feed + discharge conveyors, blue/green/white lamps) |
| L3C.6 Maalmolen | isometric mill on a platform with handrails and ladder |

**Consequence for the port:** a Godot scope built only from the mockups would
silently drop the primary visual element of every unit screen, including the two
places where tank level is actually displayed. Port the mimic from the PHOTO.

### 2. The mockups contain fabricated content

Not transcription noise — whole rows, blocks and controls that **do not exist on
the real screens**:

| Screen | Fabrication (do NOT port) |
|---|---|
| L3C.3 Bezinkafscheider | an entire safety-indicator block (`Werkschakelaar` / `Safety zone wash` / `Safety zone prewash`) — does not exist on the real unit screen |
| L3C.1 Doseer Silo | a 4th level row `Alarm laag niveau` — the photo shows exactly three |
| L3C.11 Flotatietank | a `Gewenst / Frequentie 0 Hz` row added to the `Peddelwals 5,6,7,8` card |
| L3C.16 Plasmaq | `Hand` / `Auto` buttons that are not on the real screen |
| L3C.6 Maalmolen | Start/Stop + Gewenst/Reëel sections on the `ontgrendel deurmaalmolen` card — the real card is a bare title bar with an empty body |
| BRITAS Trend zeefwisselcyclus | trend data that is fabricated, not captured |
| Hotwash 6 tankniveau | fabricated history + an omission |

### 3. Transcribed values were zeroed

Motor cards on several unit screens read `0 Hz` / `0,00 A` in the mockup while
the photo shows real readings (L3C.1: **8/8/9 Hz**, **05,76 / 06,11 / 05,12 A**,
`Loopbewaking` 15000 ms). Mockup literals are placeholders — never plant data.
Conversely this is a **gain**: `Line3CDef.gd:54` records amps `0.0` for L3C.1,
so the photo supplies the first real currents for those three screws.

### 4. A state-colour trap

A **green `Stop` button does not mean stopped.** On L3C.1 all three screws read
8-9 Hz while `Stop` is green. Running is signalled by the **green card header**
and `Status: Aan`. A porter who colours lamps from the button state will invert
every machine on the screen.

`wash3c_*` aliases and zero `wash3c_*` files exist in the repo**:

  Unconfirmed.
