## Notes / answers to open questions
- **Q18 / shredder control modes:** Confirms the **Automaat / Onderhoud (Automatic / Maintenance)** selector on the shredder control box, and a **two-hand safety interlock** ("Twee hands bediening") for manually jogging the rotor forward/backward during cleaning — both buttons must be pressed simultaneously (anti-trap safety). Blue indicator lamp = maintenance mode engaged. This mirrors SWI-040 (shredder 2) key modes I=Auto / II=Hand / III=Onderhoud; here shredder 1 uses an Automaat/Onderhoud selector plus green actuation button + fwd/rev selectors.
- **Sim relevance:** Cleaning a Lijn 3 shredder is a short 6-step LOTOTO-adjacent task where the operator switches to maintenance mode and hand-jogs the rotor via a two-hand control to clear/clean it — a small downtime event, distinct from the 89-step laserfilter change.
