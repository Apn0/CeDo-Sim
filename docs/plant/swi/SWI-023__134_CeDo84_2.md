## Notes / answers to open questions
- **Q4 / Q15 (line 3 melt filtration):** Line 3 has a **backflush filter** (with brakerplates + 2 zeven/screens + steunplaten) on **both 3a and 3b**, distinct from the "laserfilter" module. The backflush filter runs a **piston** (upper piston backflush cycle). Breaker plates are changed **every quarter (elk kwartaal)**. So line 3 extruders carry both a backflush screen-changer filter and (per SWI-054) a laserfilter.
- **Q22 (maintenance frequency):** Explicit — **brakerplate change = quarterly (elk kwartaal)** on the 3a/3b backflush filters.
- **Temperature datum:** Backflush filter parts run at **250 °C** — hence mandatory heat-resistant gloves. (Real component temperature for line-3 melt filter.)
- **steunplaten / Q re steunplaten-schade (065_CeDo78):** Confirms the **steunplaten (support plates)** and **2 zeven (screens)** are the removable filter internals; ties to the existing "steunplaten-schade" doc. Removal uses dedicated hooked tools.
