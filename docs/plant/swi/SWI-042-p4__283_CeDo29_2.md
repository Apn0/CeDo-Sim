## Answers found on this page
- **Q8 (bigbag station):** Row 20 — extruders run to **bigbag** at start-up until quality stabilizes. Confirms a bigbag catch mode exists for extruder output on lines 3a AND 3b (off-spec granulate diverted to bigbag before going to silo). Not a separate "3B bigbag station" per se, but a start-up bigbag mode on both extruders.
- **Q14 (FORM-008 row 16 full text):** This is SWI-042 (not FORM-008) but row 16 here = "Bunker vullen": 13:00, when shredder 1 knife change done, put bales on feed belt, fill bunker at setting 300 fully with film per SWI (ref SWI-048), to gain 10 min start-up. (Q14 in question set refers to FORM-008 row 16 specifically — see that doc; captured here as the closest "row 16" content.)
- **Timing chain (line 3 restart after meswissel):** 08:35 cleaning program (LOTOTO) → 13:00 watertanks refilled + bunker fill @ setting 300 → 14:00 sorteerlijn + was 3a/3b start → 14:30 compactors (≥30 min warm-up) → 15:00 extruders to bigbag until quality OK.
- **Setting 300:** bunker fill setting = "300" (matches Q16 "Bunker speed 200-800" range; 300 is a fill setting value).
- **LOTOTO** = Lock-Out Tag-Out Try-Out (safety isolation before knife change).
