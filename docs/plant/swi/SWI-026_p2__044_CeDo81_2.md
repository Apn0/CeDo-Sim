## Notes / extracted facts
- **Bale infeed rules for lijn 3 (sim-ready):** place bale gently by clamp-forklift (klem), bale LONG AXIS along belt direction; on release the bale falls apart to both sides; wrong orientation jams between the belt **schotten** (cleats) → output loss.
- **Belt loading limit:** never fill the transportband completely — consequences are (a) thermal trip of the belt motor, (b) **brugvorming** (bridging) in the shredder. Required **0,5 meter spacing between bales** — a concrete, game-usable throughput constraint.
- Forklift has a **klem** (bale clamp) attachment, not forks — vehicle model detail.
- Confirms infeed chain: heftruck → transportband (cleated, inclined) → shredder (matches page 3: opzetband → toevoerband → shredder → bunker).
