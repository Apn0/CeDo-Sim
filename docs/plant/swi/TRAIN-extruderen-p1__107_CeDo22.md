## Diagram description (embedded illustration)

Identical grey **EREMA** extrusion-line schematic to slide -2- ("EREMA" printed on machine body), with the same blue callout bubbles 1–6:

1. **(1)** Coil/roll feed (curved arrow) feeding a rising **inclined compactor conveyor belt** ("compactorband").
2. **(2)** **Compactor** — orange/red vessel labeled "counter current" with Counter Current logo; grey vent arrow at top-right.
3. **(3)** **Extruder screw/barrel** — long horizontal red screw section, tangentially connected to the compactor.
4. **(4)** Venting/degassing zone (two upward vent arrows) along the barrel.
5. **(5)** **Screen changer / filter unit** — upright block with rotor (X-in-circle) symbol at the extruder discharge.
6. **(6)** **Die / pelletizer head** — melt exits in red to the far right.
