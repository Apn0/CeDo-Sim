## Answers to open questions
- **Q10 (blauwe tank pump specs):** PARTIAL — Lijn 1 has a **pump at the "blauwe tank" feeding "was 1" (wash 1)**, run in automatic; HMI shows a pump-speed field (~58–100 [unit unclear, likely %]) [unsure]. Volume not given. Confirms blauwe tank → wash 1 water routing (see also `DIAG-blauwe-watertank__232_CeDo138.md`, `TRAIN-water-circuit-blauwe-tank__111_CeDo10.md`).
- **Q18 (shredder rpm lijn 1):** IMPORTANT — **at startup the Lijn 1 shredder should be at 26 toeren (rpm), then ramped up.** This differs from the earlier-noted "lijn1 32-50" and "Shredder1 35-60" ranges — those are running ranges; **26 rpm is the startup value.** (Reconciles Q18: startup=26, running range higher and customer-dependent.)
- **Q21 (1200 kg/hr budget line):** LEAD — the old SOP reference is coded **"I1200"** for lijn 1 startup. This "I1200" is a document/procedure code, **not** necessarily a 1200 kg/hr throughput. Possible source of confusion with the "1200 kg/hr budget" note — the "1200" here is the old **line-1 SOP identifier I1200**. [Report: Q21 "1200" likely = old lijn-1 SOP code I1200, doc 274_CeDo111 §4.]
- **Machine chain on Lijn 1 (from step 1):** frictiescheiders, intensiefwassers, **MM1**, ventilatoren, **kufferath's** (Kufferath screens/filters), MAS drogers — all must have hatches (luiken) closed before start.
