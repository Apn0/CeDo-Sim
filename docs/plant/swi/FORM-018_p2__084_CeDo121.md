### Was 3b *(section header, highlighted yellow)* — Wash line 3B
- "Rafter aflaten en zeefdek reinigen. Schraperbak laten lopen zodat rafter goed leeg is." *(Drain the Rafter and clean the sieve deck. Run the scraper tray so the Rafter is fully empty.)*
- "Flotatie tank aflaten, schraperbak laten lopen zodat deze goed leeg is." *(Drain the flotation tank; run the scraper tray so it is fully empty.)*
- "Sensor flotatie tank was 3b reinigen." *(Clean the flotation-tank sensor of wash 3b.)*
- "Intrek rol flotatie tank ontdoen van slierten" *(Draw-in roller of flotation tank — remove strands)*
- **(bold)** "Vuilsnipper silo en cyloon binnenin de wanden schoon spuiten met HD reiniger/lange lans" *(Dirt-shredder [Vuilsnipper] silo and cyclone — hose the inner walls clean with HD [high-pressure] cleaner / long lance)*
- "Fricki li/re schoonmaken." *(Fricki [frictiewasser] left/right — clean)*
- "Intensiefwassers links en rechts schoonmaken via luik aan zijkant." *(Intensive washers left & right — clean via the side hatch)*
- "Ventilator 210 /achter de intensiefwasser waaier deur openen en achterkant waaier schoon maken" *(Fan 210 / behind the intensive washer — open the impeller door and clean the back of the impeller)*
- "Droger temperatuur sensor controleren op aangekoekte troep." *(Dryer temperature sensor — check for caked-on dirt)*
- "Thermische droger onder verdeelwals vrijmaken van aangekoekte troep." *(Thermal dryer — clear caked-on dirt under the distribution roller)*
- "Thermische droger onder grote cycloon, valse lucht aanzuig pijp van ventilator vrijmaken van troep" *(Thermal dryer under the big cyclone — clear the fan's false-air intake pipe of dirt)*
- "Thermische droger alle luiken open en schoon maken" *(Thermal dryer — open all hatches and clean)*
- "Stofzak vuilsnipper silo leegmaken" *(Empty the dust bag of the dirt-shredder silo)*
- "Valse lucht aanzuig intensiefwassers ingang zijde schoon spuiten" *(Hose clean the false-air intake on the inlet side of the intensive washers)*

## Answers to open questions
- **Q4 (Rafter, 3B):** Strong evidence the **Rafter is a wash-line-3B machine with a "zeefdek" (sieve deck) and a "schraperbak" (scraper tray)** — it is drained and the sieve deck cleaned, scraper tray run to empty it. So the "Rafter" is a screening/de-watering unit (sieve-deck + scraper) on line 3B. Make/type still not named here, but the function is now clear: a sieve-deck separator with scraper discharge. Quote: "Rafter aflaten en zeefdek reinigen. Schraperbak laten lopen zodat rafter goed leeg is."
- **Q3 / M11 family:** Names **M11b** as the "Uitgang schroef" (outfeed screw) on this line — distinct from M11a. Quote: "Uitgang schroef M11b vrij maken van folie slierten." (Supports that M11a and M11b are separate screws; does not confirm the M11a dosing/infeed sharing question.)
- **Q8 (does 3B have a bigbag station?):** Not answered — no bigbag station in this list (though this is a cleaning list, not an equipment inventory).
- **Q28 (TITECH/TOMRA):** Confirms **8 TOMRA/TITECH optical glasses/lenses ("Alle 8 de tomra glaasjes")** on line 3, i.e. 8 sensor windows to keep clean. Quote: "Alle 8 de tomra glaasjes."
- **New machine inventory for line 3 (both 3A & 3B), useful for the sim:**
  - Herbold droger (Herbold dryer) — with temp sensor + hatches
  - M14 verdeelwals (distribution roller)
  - M11b uitgang schroef (outfeed screw)

  - RVS bak onder cycloon thermische droger (SS tray under thermal-dryer cyclone)

  - Sensors: Shredder 1, Bunker, Shredder 2, Balenpers (4), Perscontainer (4), sorteerlijn silo 3a/3b, MAS bak 3a/3b, Extruder silo 3a/3b, Compactor 3b
