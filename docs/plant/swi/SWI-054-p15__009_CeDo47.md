## Notes / open-question hits
- Poka-yoke detail: uitdraaischroef has a **paspen** engaging an **uitsparing** in the schraper — cannot be assembled wrong. (Nice sim assembly-minigame constraint.)
- Reassembly sequence: seat scraper → close deur (filter held in door!) → pre-greased bolts, 1 hand-tight first → run up with **kleine luchthamer** (air impact) → later torque **op moment** (to torque spec). Torque value not on this page (may be on p.16-17).
- Plural "**Laserfilters**" in step 57 confirms multiple filter discs in the unit (matches "1e laserfilter" on p.7).
