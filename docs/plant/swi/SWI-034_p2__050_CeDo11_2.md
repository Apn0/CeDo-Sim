## Values / facts
- Shredder 1 (lijn 3) control panel has: mains/spanning schakelaar, **Automaat / Onderhoud** selector, and a **two-hand jog control** that turns the rotor **vooruit of achteruit** (forward or reverse) only while both buttons are held — safety interlock during wire cleaning.
- Completes the SWI-034 sequence: (p1) run line empty per SWI-035 → open shredder per SWI-027 → block rotor per SWI-033 → cut wires; (p2) re-energize → onderhoud mode → two-hand jog rotor to expose more wire wraps.
