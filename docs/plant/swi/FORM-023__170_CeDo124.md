## Notes / open-question hits
- **Q23 (Voertuig_controle: does "Machine nr" cover the mast lift?):** ANSWERED. FORM-023 has THREE separate vehicle-ID header fields — **Heftruck nr / Machine nr / Merlo nr** — so "Machine nr" is a **generic machine/vehicle identifier field distinct from the forklift (Heftruck) and the Merlo telehandler**. The **mast is covered as inspection items 7-10** (hydraulic mast guide rollers, mast full up, mast tilt, clamp/forks open-close) on whichever vehicle is being checked — the mast is NOT a separately-numbered "Machine nr"; it is inspected as part of the vehicle. So the single daily form covers forklift + Merlo + any "Machine nr" vehicle, and the mast-lift checks (rows 7-10) apply to the mast-equipped units. This form is the real-world basis for the sim's Voertuig_controle checklist.
- **Q23 detail — the Merlo:** the plant's telehandler is a **Merlo** (dedicated "Merlo nr" field) — confirms the mast-lift/telehandler vehicle brand for the sim vehicle fleet.
- Shift structure visible: each day split into **OD/MD/ND** (morning/afternoon/night) — corroborates the sim's shift model (though not the full 2-2-2-4 calendar).
- Colour rule: RED-marked items = vehicle rejected / not to be used ("Veiligheid boven alles"). Good for sim gating logic on vehicle readiness.
