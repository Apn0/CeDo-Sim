## Notes / answers
- **Q4/Q15/Q25 (line 3 architecture):** This SWI explicitly scopes to **laserfilter on line 3A AND 3B** — so both 3A and 3B have an Erema-type laserfilter (melt filter) at the extruder, changed at **280/300 bar** melt-pressure differential. Confirms 3A and 3B share the same laserfilter changeover procedure. (The "Rafter" 3B machine question Q4 not answered here.)
- **References establish machine make:** **Erema** — line 3 extruders are Erema machines (Handleiding boek Erema). Corroborates laserfilter = Erema Laserfilter melt-filtration system. Directly supports Q15 laserfilter identity.
- **Purge procedure = SWI-017** ("extruder 3A / 3B leegdraaien"). Cross-reference target not yet in corpus — flag to hunt for SWI-017.
- **Safety spec:** melt/material temperature 200°C; PPE = shoes/glasses/hearing/gloves.
- **Compactor precedes the extruder on line 3** (pre-densifying compactor feeds extruder). Must be empty-run and de-caked before a filter change. Relevant to Q24 (feed density: this compactor densifies film before the extruder).
