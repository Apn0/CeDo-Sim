## Notes / answers to open questions
- **Q28 (TITECH/TOMRA):** This is the TOMRA/TITECH NIR sorter calibration procedure. Confirms the machine is a **near-infrared (NIR)** optical sorter with **multiple scanners/sensors** (at least two, switchable in software). Calibration uses a reference **plaat** (calibration plate/tile) and validates that the reference **peak reaches value 1** after calculation to pass. Calibration is done via a touchscreen HMI with per-scanner selection. (This is p8/8; the sorting programs / ejection content are likely on earlier pages of SWI-009.)
