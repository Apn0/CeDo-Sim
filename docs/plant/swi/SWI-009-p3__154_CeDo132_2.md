## Notes / answers — Q28 (TITECH / TOMRA)
- **Login PIN for the Titech/Tomra calibration UI = "4321"**, confirm with "ok"; password reached via far-right "passwoord" button.
- **NIR sorter** = TITECH/TOMRA near-infrared unit. Calibration uses a **kaliberbepalingsplaat** (calibration-determination plate) laid on the belt; software identifies it as a **white circle** on a virtual band, and a correct calibration yields a flat spectrum (horizontal line at height 1).
- Calibration UI is per-**scanner** ("Scanner 1", selectable sensor top-right) — implies multiple NIR scanners/sensors.
- Status values observed on screenshot: **Intensiteit 3456**, **Plaatbreedte 11,7 cm** [unsure: reading]. These are calibration diagnostics, not sorting-program contents.
