## Values / facts
- Lijn 3 balenpers uses **5 draden** (5 wires) per bale tie-off; all 5 must exit ("geen 5 maar minder draden naar buiten" = fault condition).
- Baler has a **verticale knoperij** (vertical knotter) and a **spindel** that jams when wire birdnests.
- Recovery cost of a wire jam: **8 uur stopstand** + one extruder stopped → **7200 kg output verlies**.

## Open-question hits
- **Q9 (line capacities):** 7200 kg lost when an extruder is stopped during the 8-hour spindle-freeing stop → implies **~900 kg/h per extruder** on lijn 3 (7200/8). Doc id: SWI-031 p2, step 5: "stopstand van 8 uur ... output verlies 7200kg".
- **Q21 (1200 kg/hr budget):** 900 kg/h per extruder here suggests the 1200 kg/hr budget figure is NOT a single lijn-3 extruder; possibly whole-line or another line. Hint only.
- Sim relevance: baler wire jam = high-cost failure event (8 h downtime + 7.2 t lost output) preventable by a cheap recurring check — perfect risk/reward mechanic.
