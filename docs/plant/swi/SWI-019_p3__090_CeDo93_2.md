## Answers to open questions
- **Q30 / signal lamp semantics (sim UI):** Press-container status beacon — **Groen (green) = OK/running; Geel (yellow) = 75% full → change container; Rood (red) = storing (fault).** Container-full threshold = **75%**. Quote: "Groen=installatie OK en loopt. Geel is 75 % vol, wisselen! Rood=storing."
- **Perscontainer mechanics (sim):** Container is driven left/right via 'Links'/'Rechts' buttons, auto-stops in position, coupled to the press via 'aankoppeling sluiten', then rotary knob → 'auto' for fully automatic running; full container's opening is covered with a tarpaulin ("zeil"). Feed belt = **"opzetband"** (riser/feed belt). The signal sensor sits behind the opzetband.
