## Notes / answers to open questions
- **Q16 (Bunker speed 200-800 unit):** Not the speed unit, but relevant — the **bunker "full" setpoint is value 2.0** (dimensionless level/fill indicator on the SCADA); when reached the restart button resets to 0 and the sort line can auto-start. So the bunker level indicator here runs on a small numeric scale (~0-2.0), distinct from the "bunker speed 200-800" motor-speed parameter.
- Startup sequence for the sort-line section: **automatic button → preheat button (wait for green block on display, then green button) → belt runs → bunker fills to 2.0 → ready for automatic sort-line start.** Authored by TD (Technical Department).
