## Notes / answers to open questions
- **Q15 / laserfilter:** The LF 2 assembly stack includes **breaker plates ("brakerplates")** — perforated melt-support plates behind the filter screens — fixed with **new Allen bolts, only hand-tight** (must be releasable next change). Changing the breaker plates is a separately-scoped **"Extra module"** within the SWI. Each filter carries an **engraved ID number on its rim** that operators log on a form (traceability). Auger ends greased with copper grease. Confirms the melt-filter stack = breaker plate + filter screen (pair) + clamp ring + scraper + twin augers.
- **Q33-adjacent:** row 64 shows a **FILLED-IN registration/log form** photographed (numbers recorded per change) — evidence that per-change laserfilter logs exist, though this is a filter-ID log, not an Extruderlijst.
