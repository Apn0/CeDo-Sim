## Notes / answers to open questions
- **Q24 / baler & container handling:** Documents the **perscontainer wissel** — swapping the container at the press (**pers/balenpers**). The press uses **buizen (tubes/pins)** inserted through side doors, a **vergrendel pen** that must seat in the **eindcontact** (limit switch) before operation, and a **"Gitterhub"** selector set to position 2. ("Gitterhub" = German for grid/gate lift/stroke — the press's grid-lift function.)
- **Maintenance/safety contact:** References the **"MH techniek storings dienst"** (MH = maintenance/technical breakdown service) and a **werkaanvraag** (work request) system — the plant's maintenance escalation path. (MH likely "Machine/Mechanical" or a contractor abbreviation.)
- **Roles include "invoerders"** (feeders/loaders) — an operator role class distinct from operators/extruder operators.
- SWI-019 is a 3-page instruction; p2 = 056_CeDo92_2, p3 = 090_CeDo93_2 (already digested). This is page 1.
- No throughput/setpoint numbers on this page (mechanical swap procedure).
