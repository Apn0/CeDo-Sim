### Step 26 — "Lucht kleppen / Air valves / nozzles wisselen" ("Air valves / nozzles changing")
- **Let op:** (none pictured in this row)
- **Omschrijving (verbatim):**
  "Nadat de 3 nozzle programma's zijn doorlopen, en er is doorgegeven welke Nozzles / klepjes defect aangeven, moet de TD deze nozzles op diezelfde dag wisselen.
  Het advies van Tomra is dan, om bij minimaal 10 defecte nozzles die dicht bij elkaar zitten, de wissel te doen, en bij maximaal 20 defecte nozzles sowieso een wissel te doen. Dus bij 3 defecte nozzles, schrijf je deze op, om deze een volgende keer te wisselen wanneer je er dus 10 tot 20 defect hebt."
  - Gloss: After the **3 nozzle programs** have run and it's reported which nozzles/flaps indicate defective, the **TD (Technische Dienst = maintenance)** must change these nozzles the **same day**. Tomra's advice: replace when **minimum 10 defective nozzles** are close together; at **maximum 20 defective** always do a swap. So with only 3 defective, note them down and swap next time once you have **10 to 20 defective**.
- **Foto/right cell (verbatim, highlighted):**
  "Zie Tomra technical documentation hoofdstuk **11.3.4** hoe de ventielen te wisselen.
  Let op, dit advies is afkomstig van Tomra bezoek en gesprek op **13-4-23**."
  - Gloss: See Tomra technical documentation chapter 11.3.4 for how to change the valves. Note: this advice comes from a Tomra visit and discussion on 13-4-2023.

## Answers to open questions
- **Q28 (TITECH/Tomra programs/nozzles):** The Tomra sorter runs **3 nozzle test programs** to identify defective air-valve nozzles. Ejection uses **air valve nozzles/klepjes**. Replacement policy: swap when **10–20 defective nozzles** accumulate (min 10 if clustered, always by 20); <10 just log for later. TD (maintenance) does same-day swap. Ref: Tomra technical documentation **ch. 11.3.4**, advice dated 13-4-2023. (Complements Werking-Titech-tomra docs 172-174.)
