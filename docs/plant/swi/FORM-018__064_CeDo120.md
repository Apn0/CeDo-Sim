## Machine inventory / abbreviations decoded (load-bearing)

**Sorting line 3 train:** Shredder 1 → Shredder 2 (with zeefkant/screen) → belt → Bunker roll → 4× Titech/Tomra units (each has *luchtbalken* air bars + *splitrollen* split rolls + *blauwe huizen* blue housings) → IFE screen + Spaleck screen → Balenpers (baler with ram + poets/cleaning programme).

**Extruder train (both 3a and 3b are EREMA):** Compactor (rim + grate/rooster + water injection + moisture extraction + hood + belts) → Extruder cylinder (blue caps underneath) → Vacuum degassing (vacuum tank + tankje at rear + side water filters + screen) → Weegschaal (weigh scale) → Deltoid fans w/ MAS bins → Laserfilter → **Kopfilter/brakerplates (head filter breaker plates)** → Extruder silo (with cyclone + korf/basket) → Zeef centrifuge + e-motor centrifuges → Heetafslag (hot-cut/pelletiser knives).

**Wash 3a train:** LA1 → (Zandscheider / sand separator + LRD) → LA2 → LA3 → Frictiewasser → **C1** → Intensiefwasser M8 → V4 zeef → Mengsilo (with vlinder/butterfly valve + paddenstoel/mushroom + stofzak/dust bag) → Vuilsnipper silo + cycloon → Herbold droger (with verdeelwals).

## Cross-refs to OPEN QUESTIONS — direct hits

- **Q2 (what is block C1 on lijn 3A between Frictiewasser and Frictiescheider):** CONFIRMED C1 is a distinct wash-line tank/vessel that is drained & cleaned ("C1 aflaten en schoonmaken"), located right after the Frictiewasser and before the Intensiefwasser M8 in the wash 3a sequence: `Frictiewasser → C1 → Intensiefwasser M8`. Quote: "Frictiewasser aflaten / C1 aflaten en schoonmaken / Intensiefwasser M8 schoon spuiten". So C1 is a tank between the friction washer and the intensive washer (M8). (Still no make/type; it is a numbered vessel — likely a concentrator/buffer tank "C" = clarifier/concentrator.)
- **Q11 (what do LA1/LA2 stand for):** Doc confirms LA1, LA2, LA3 are three sequential wash-line vessels each individually drained. LA1 pairs with a Zandscheider (sand separator) and LRD (a suction/vacuum device). Still no expansion of "LA" here, but establishes there are **three** LA tanks (LA1/LA2/LA3) in wash 3a, not two. LRD = the vacuum truck/suction unit used to empty LA1 and the sand-separator.
- **Q13 (FORM-008 row 22 duplicate "Compactor 3a rand afzuiging" — should it be 3B):** Supporting context — here the compactor rim/edge cleaning is explicitly "Compactors 3a en 3b rand reinigen" and "Rooster én rand ... van beide extruders", confirming BOTH 3a and 3b compactors have a rand (rim) afzuiging (extraction). So a FORM-008 that lists compactor rand afzuiging twice plausibly intends one row for 3a and one for 3b (the duplicate should read 3B). Supports the hypothesis.
- **Q4 (the "Rafter" 3B):** Not named on this page. No "Rafter." (3B extruder train listed above uses laserfilter + kopfilter/brakerplates + EREMA compactor.)
- **Q15 (laserfilter position):** CONFIRMED laserfilter + kopfilter/brakerplates ("head filter breaker plates") are downstream filtration on the extruder; laserfilter and brakerplates are removed/changed as a pair on 3b. Order: extruder → laserfilter → kopfilter brakerplates → silo/pelletiser.
- **Q25 (did BOPP run on 3A/3B):** Not mentioned.
- **Q1 (ZSS):** Not on this page.
